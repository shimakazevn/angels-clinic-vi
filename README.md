# Patch Việt Hóa - 天使の早漏治療クリニック (Angelic Clinic)

Bản patch Tiếng Việt dành cho game **天使の早漏治療クリニック (RJ01644040)**.

---

## 📥 Cách cài đặt

### Cách 1: Tự động tải & patch từ GitHub (Nhanh nhất)
1. Tải file `AUTO_UPDATE_PATCH_VIET_HOA.bat`.
2. Thả file `.bat` vào thư mục game (cùng nơi chứa `Game.exe`).
3. Chạy file `.bat` để tự động tải và cài đặt bản patch mới nhất.

### Cách 2: Cài thủ công (Offline)
1. Tải gói ZIP từ GitHub về máy và giải nén.
2. Copy file `CAI_DAT_PATCH_VIET_HOA.bat` và thư mục `patch` vào thư mục game.
3. Chạy file `CAI_DAT_PATCH_VIET_HOA.bat` để cài đặt.

---

## 📌 Nội dung bản patch
- Dịch toàn bộ hội thoại và cốt truyện.
- Việt hóa giao diện, tùy chọn plugin và menu.
- Sửa font chữ Tiếng Việt không bị lỗi font hay ngắt dòng.
- Giữ nguyên ảnh UI tiếng Anh & nút bấm 3D Photoshop.
